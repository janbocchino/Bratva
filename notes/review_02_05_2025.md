## USD asset creation on failed asset read

Don't do this:

```ts
const usdAsset = Fn.pipe(
		assetReadRepo.getAsset({ ticker: 'USD' }),
		E.catch('name', {
			failure: 'PortError',
			onFailure: (err) => {
				const cause = (err as { cause?: { name?: string; _tag?: string } }).cause;
				if (
					cause?.name === 'AssetNotFoundError' ||
					cause?._tag === 'AssetNotFoundError'
				) {
					return assetWriteRepo.createAsset({
						name: 'US Dollar',
						ticker: 'USD',
					});
				}
				return E.fail(err);
			},
		}),
	);
```

It's just bad practice. You're creating an asset that's a fundamental part of the system only when a user fails to read it. Instead, you should write an SQL script to insert key entries like that into the database (for example, in `scripts/`) as a post-migration hook/step.
